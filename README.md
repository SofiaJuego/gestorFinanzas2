# 💰 Gestor de Finanzas Personales (IEFI)

Aplicación web desarrollada como Instancia de Evaluación Final Integradora (IEFI) para el control y seguimiento de finanzas personales, permitiendo registrar ingresos, egresos, visualizar balances globales y analizar estadísticas financieras de forma visual e interactiva.

El proyecto se encuentra desplegado y funcional en producción a través de GitHub Pages: https://sofiajuego.github.io/gestorFinanzas2/
